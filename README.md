# Pacman-Style Game

A 2D maze game written in C++ using Allegro.

## Planned features
- Player movement and wall collision
- Pellets and scoring
- Ghost movement
- Lives and win/lose conditions
- Restart support

## Build instructions
Compile with this command: g++ -std=c++17 -Wall -Wextra -g src/main.cpp -o pacman.exe -lallegro
